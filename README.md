ChatApp Backend – Spring Boot (Services + JPA + Unit Tests)
This project is a backend module for a simple Chat Application, built with Spring Boot and Spring Data JPA.
It demonstrates clean service‑layer architecture, repository interaction, validation, and unit testing using JUnit 5 and Mockito.
The codebase includes functionality for managing:
• Users
• Profiles
• Messages
• Tags
It also includes unit tests for core services, showcasing test‑driven development and mocking techniques.
