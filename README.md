ChatApp Backend – Spring Boot (Services + JPA + Unit Tests) <br>
This project is a backend module for a simple Chat Application, built with Spring Boot and Spring Data JPA. <br>
It demonstrates clean service‑layer architecture, repository interaction, validation, and unit testing using JUnit 5 and Mockito. <br>
The codebase includes functionality for managing: <br>
• Users <br>
• Profiles <br>
• Messages <br>
• Tags <br>
It also includes unit tests for core services, showcasing test‑driven development and mocking techniques.
